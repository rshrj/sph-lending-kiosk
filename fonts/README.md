# Fonts

The SPH look uses two commercial typefaces that are **not** in this repository (their licences don't
allow redistribution):

- `ProximaNova-Regular.ttf`, `ProximaNova-Bold.ttf` (Proxima Nova, Mark Simonson Studio)
- `AlternateGothicNo2Pro-Regular.ttf` (Alternate Gothic No2)

If you have a licence, put the TTFs here with exactly these names and rebuild. Without them CMake
prints a warning and the app falls back to a system font; everything else works.

Inter (OFL, `OFL-Inter.txt`) is open and included.
